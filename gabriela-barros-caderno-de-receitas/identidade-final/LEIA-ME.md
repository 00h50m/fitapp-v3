# Gabriela Barros — Caderno de receitas · Identidade visual v1.0

A assinatura e todos os elementos manuscritos são a **letra real da Gabriela**, vetorizados pela linha central do traço
a partir das fotos das amostras. O desenho das letras foi preservado; só o traço foi limpo e uniformizado.

## Pastas
| Pasta | Conteúdo |
|---|---|
| `svg/` | 24 SVG (6 versões × 4 cores), tudo em curvas, grupos nomeados |
| `svg-traco-e-texto-editaveis/` | 20 SVG: assinatura como linha com traço vivo (espessura ajustável) e textos em Courier Prime editáveis |
| `pdf/` | 24 PDF vetoriais para gráfica |
| `png/` | 24 PNG transparentes, 3.000 px no maior lado |
| `elementos-manuscritos/` | "confeitaria", "Suspiro", "Feito com amor", "Receita nº" e números 0–9, em azul, morango, preto e branco (SVG, SVG com traço editável, PDF, PNG) |
| `padrao/` | Padrões "suspiros" e "caderno" (tile 600×600) em SVG, PDF, PNG + prévias 3×3 |
| `guia/` | Guia da marca (PDF, 11 páginas) |
| `fontes/` | Courier Prime (Alan Dague-Greene · Google Fonts · SIL OFL 1.1) |
| `mockups/` | Ficha de receita, tags, caixa de bolo, cartão, perfil (ilustrativos) |
| `apresentacao/` | Prancha de apresentação (PNG + PDF) |
| `_scripts/` | Código-fonte e dados vetorizados que geram todos os arquivos |
