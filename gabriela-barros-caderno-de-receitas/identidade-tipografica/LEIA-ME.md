# Gabriela Barros — Caderno de receitas · Identidade tipográfica v1.0

Mesma ideia do "caderno de receitas" (suspiro, carimbo, paleta, Courier Prime, padrões), com o nome em
**Fraunces Soft** no lugar da caligrafia. O pingo do "i" de Gabriela é um suspiro.

## Pastas
| Pasta | Conteúdo |
|---|---|
| `svg/` | 24 SVG (6 versões × 4 cores), tudo em curvas, grupos nomeados |
| `svg-texto-editavel/` | 16 SVG com o nome (Fraunces) e os textos (Courier Prime) como texto ativo — instale as fontes de `fontes/` |
| `pdf/` | 24 PDF vetoriais para gráfica |
| `png/` | 24 PNG transparentes, 3.000 px no maior lado |
| `elementos/` | "feito com amor", "suspiro", "confeitaria" (Fraunces Italic), "RECEITA Nº" e números 0–9 (Courier Prime), em 4 cores |
| `padrao/` | Padrões "suspiros" e "caderno" (tile 600×600) + prévias 3×3 |
| `guia/` | Guia da marca (PDF, 11 páginas) |
| `fontes/` | Fraunces (Undercase Type) e Courier Prime (Alan Dague-Greene) — Google Fonts, SIL OFL 1.1 |
| `mockups/` | Ficha de receita, tags, caixa de bolo, cartão, perfil (ilustrativos) |
| `apresentacao/` | Prancha de apresentação |
| `_scripts/` | Código que gera tudo |

Versões: `logo-principal` · `logo-horizontal` · `monograma` · `carimbo` · `suspiro` · `nome`
Cores: `colorida` · `azul` · `preto` · `branco`

Configuração do nome: Fraunces wght 600 · opsz 144 · SOFT 100 · WONK 0 · espaçamento −10/1000.
No texto editável o "i" é o caractere sem pingo (ı, U+0131) e o suspiro é um elemento separado.
